# Bài làm
- Prompt:
    - Prompt 1: Bạn là chuyên gia Marketing cần sản phẩm nghiên cứu đối tượng khách hàng mục tiêu và xây dựng danh sách các nỗi đau (pain points) mà sản phẩm giải quyết.
    - Prompt 2: Dựa trên output của Prompt 1, thiết lập dàn ý chi tiết bài viết PR đầu ra cuối cùng cần đạt cấu trúc chuẩn SEO bao gồm:
    - Tiêu đề thu hút (Headline).
    - Đoạn mở đầu (Lead) hấp dẫn giải quyết pain points.
    - Các tiệu đề con (H2, H3) tương ứng với dàn ý.
    - Lời kêu gọi hành động (CTA) rõ ràng ở cuối bài.
    - Prompt 3: Dựa trên dàn ý ở Prompt 2, triển khai viết chi tiết từng phần của bài viết và tối ưu hóa từ khóa SEO. Viết một bài PR chuyên sâu (khoảng 1000 - 1500 từ) giới thiệu giải pháp AI Chatbot mới cho doanh nghiệp. Thiết lập quy tắc xử lý khi AI viết bài dài bị ngắt quãng giữa chừng (đạt max token): cung cấp câu lệnh điều khiển tiếp tục tạo chính xác.
